Attendance kiosk

This device marks attendance for one class. Open the class in the admin console, choose Kiosk device, and paste the code it gives you below. Students then just look at the camera — nobody types an ID or a password.

The code works for this class only and expires with it. It cannot read the roster, enrol anyone, or sign in as a student.
